🚀 Kabuby — Deploy MeLi Search Worker

Crea el Worker de Cloudflare que permite al Cazador de Arbitraje obtener datos REALES de Mercado Libre

⚠️ ¿Por qué necesitamos esto?
api.mercadolibre.com bloquea con HTTP 403 CORS todas las peticiones desde browsers y también rechaza proxies públicos (allorigins, corsproxy.io, cors.sh). Un Cloudflare Worker propio hace la petición server-to-server sin restricciones CORS y devuelve los datos con cabeceras que permiten leerlos desde kabuby.com. Es gratis en el plan free de Cloudflare.
1

Abrir Cloudflare Dashboard

Ve a dash.cloudflare.com e inicia sesión.
En el menú lateral izquierdo haz clic en "Workers & Pages".
Luego clic en el botón azul "Create application" → pestaña "Workers" → "Create Worker".

2

Nombrar el Worker

En el campo Name escribe exactamente: kabuby-meli-search
Haz clic en "Deploy" (puedes ignorar el código de ejemplo por ahora).

3

⭐ Reemplazar el código del Worker

Después del deploy, haz clic en "Edit code" (botón azul arriba a la derecha).
Selecciona todo (Ctrl+A) → Borra → Pega este código:

/** * Kabuby MeLi Search Proxy Worker v1.0 * Endpoint: /search?site=MLBR&q=producto&limit=10 * Endpoint: /health * * Sitios válidos: MLBR, MLMX, MLCO, MLAR, MLCL, MLPE, MLUY, MLEC */ const ALLOWED_SITES = ['MLBR','MLMX','MLCO','MLAR','MLCL','MLPE','MLUY','MLEC']; const ALLOWED_ORIGIN = '*'; // Puedes restringir a 'https://kabuby.com' export default { async fetch(request, env, ctx) { // Handle CORS preflight if (request.method === 'OPTIONS') { return new Response(null, { status: 204, headers: corsHeaders() }); } const url = new URL(request.url); // Health check if (url.pathname === '/health' || url.pathname === '/') { return jsonResp({ status: 'ok', worker: 'kabuby-meli-search', version: '1.0' }); } // Search endpoint if (url.pathname !== '/search') { return jsonResp({ error: 'Usa /search?site=MLBR&q=producto&limit=10' }, 400); } const site = (url.searchParams.get('site') || '').toUpperCase(); const q = url.searchParams.get('q') || ''; const limit = Math.min(parseInt(url.searchParams.get('limit') || '10'), 50); if (!ALLOWED_SITES.includes(site)) { return jsonResp({ error: 'site inválido. Usa: ' + ALLOWED_SITES.join(', ') }, 400); } if (!q.trim()) { return jsonResp({ error: 'El parámetro q (búsqueda) es requerido' }, 400); } const meliUrl = `https://api.mercadolibre.com/sites/${site}/search?q=${encodeURIComponent(q)}&limit=${limit}`; try { const resp = await fetch(meliUrl, { headers: { 'User-Agent': 'Mozilla/5.0 (compatible; KabubySearch/1.0; +https://kabuby.com)', 'Accept': 'application/json', 'Accept-Language': 'es-419', }, cf: { cacheTtl: 180, cacheEverything: true } }); const body = await resp.text(); return new Response(body, { status: resp.status, headers: { ...corsHeaders(), 'Content-Type': 'application/json', 'Cache-Control': 'public, max-age=180', 'X-Proxy': 'kabuby-meli-search', 'X-Site': site, } }); } catch (e) { return jsonResp({ error: 'Fetch a MeLi falló: ' + e.message }, 502); } } }; function corsHeaders() { return { 'Access-Control-Allow-Origin': ALLOWED_ORIGIN, 'Access-Control-Allow-Methods': 'GET, OPTIONS', 'Access-Control-Allow-Headers': 'Content-Type', 'Access-Control-Max-Age': '86400', }; } function jsonResp(data, status = 200) { return new Response(JSON.stringify(data), { status, headers: { ...corsHeaders(), 'Content-Type': 'application/json' } }); }

Después de pegar el código, haz clic en el botón "Deploy" (arriba a la derecha del editor).
Cloudflare te mostrará la URL del worker: algo como https://kabuby-meli-search.TU-USUARIO.workers.dev

4

Probar que el Worker funciona

Abre en tu browser: https://kabuby-meli-search.TU-USUARIO.workers.dev/health
Deberías ver: {"status":"ok","worker":"kabuby-meli-search","version":"1.0"}
Luego prueba una búsqueda real:
https://kabuby-meli-search.TU-USUARIO.workers.dev/search?site=MLBR&q=crema+coreana&limit=5
